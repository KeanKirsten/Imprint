# Figma Landing Page Design

**Date:** 2026-06-23
**Status:** Approved

---

## Overview

Replace the current scattered-card landing with the Figma "Landing page" design
(node 17:72): a light, typographic layout where two centred columns of repeating
effect labels react to the cursor with an elastic horizontal cascade, and a floating
preview card shows a static thumbnail of the hovered effect. Clicking a label enters
that effect's workspace.

Source design: `https://www.figma.com/design/TzTo8lqLfSD1ztSp7OruFc/...?node-id=17-72`

---

## Decisions (locked)

- **Fonts:** embed the real trial fonts (provided): **Lay Grotesk** (labels + meta) and
  **Azurio** (wordmark), via `@font-face` from `public/fonts/`.
- **Preview card:** static thumbnails (one image per effect), provided by the user in
  `public/previews/` as `bleed.png`, `particle.png`, `ascii.png`.
- **Cascade:** custom vanilla spring (rAF), no new dependency.
- **Navigation:** clicking a label calls `enterEffect(effect)`.
- **Columns:** repeat only the three effect labels (no woven client names).
- **Replacement:** the old `.effect-card` parallax landing and its live canvas previews
  are fully removed.

## Visual spec (from Figma)

- **Background:** soft grey `#ecefed` with a faint vertical gradient and a subtle noise
  grain overlay (inline SVG `feTurbulence`, very low opacity).
- **Text colour:** `#0e0e0f`.
- **Header:**
  - Wordmark "Imprint" — Azurio Medium, 24px, letter-spacing -1.44px, top-left (40px/40px).
  - Meta — Lay Grotesk Medium, 14px: "Visual Effects Tool" and "2025" top-right (40px),
    gap 24px.
- **Labels:** Lay Grotesk Medium, 24px, letter-spacing -1px, line-height ~45px, sentence case.
- **Columns:** two vertical columns, centred as a pair, modest gap. Each column fills the
  viewport height with repeated labels (enough rows to overflow comfortably; clipped).

## Behaviour (`src/landing/index.ts` — full rewrite)

`initLanding()` does the following:

### 1. Build columns
- Two columns. For each, compute `rowCount = ceil(viewportHeight / ROW_H) + 4` (ROW_H ≈ 45).
- Create `.lp-label` elements cycling `LABELS`. Each label stores its effect key
  (`data-effect`), its column index, and its row index.
- Store a flat array of label records: `{ el, col, row, effect, baseX, x, v }`.

### 2. Cascade spring (rAF loop, always running)
- Track `hovered: { col, row } | null`.
- Each frame, for every label compute a **target X offset**:
  - If nothing hovered, or label is in the other column → target 0.
  - Else `d = row - hoveredRow`; `falloff = exp(-(d*d) / (2 * SIGMA*SIGMA))`;
    `target = DIR * MAX_DISP * falloff`, where `DIR = -1` for the left column and `+1`
    for the right column (push outward, away from centre), `MAX_DISP ≈ 90`, `SIGMA ≈ 2.2`.
- Integrate a spring toward target (semi-implicit):
  `v += (target - x) * STIFFNESS; v *= DAMPING; x += v;` with `STIFFNESS ≈ 0.14`,
  `DAMPING ≈ 0.72`. Apply `el.style.transform = translateX(x)px` (round to 2dp).
- This gives the elastic bow that settles smoothly on mouse-out (target → 0 everywhere).

### 3. Preview card
- On `mouseenter` of a label: set `hovered`, populate the card (tag, name, thumbnail via
  `background-image`), position it beside the label (to the inner side, vertically centred on
  the label's rect, clamped to viewport), and add a `visible` class (CSS fades/scales it in).
- On `mouseleave` of a label: if it's the active one, clear `hovered` and hide the card.
- Thumbnail loading uses an `Image()` with an `onerror` fallback that applies a flat accent
  background + the label text so a missing file degrades gracefully.

### 4. Navigation
- On `click` of a label: `enterEffect(label.effect)`.

### 5. Resize
- On `window.resize`, rebuild columns (debounced) so row counts refit.

Tunable constants (`ROW_H`, `MAX_DISP`, `SIGMA`, `STIFFNESS`, `DAMPING`, `COL_GAP`) live at the
top of the file.

## Styles (`src/styles/landing.css` — full rewrite)

- `#view-landing`: light gradient background (`#eef0ee` → `#e6e8e6`), default cursor.
- `.lp-grain`: absolute inset-0 overlay, the SVG noise data-URI, `opacity: 0.05`,
  `mix-blend-mode: multiply`, `pointer-events: none`.
- `.lp-header`: absolute top bar, padding 40px, flex space-between, `#0e0e0f`.
  - `.lp-wordmark`: `font-family: 'Azurio Trial'`, 24px, `letter-spacing: -1.44px`.
  - `.lp-meta`: `font-family: 'Lay Grotesk Trial'`, 14px, two spans, gap 24px.
- `.lp-columns`: absolute inset-0, flex centre, `gap: COL_GAP` (≈ 120px), overflow hidden,
  `align-items: flex-start`, padded top so labels start below the header.
- `.lp-col`: flex column; fixed width so the translateX bow reads clearly.
- `.lp-label`: `font-family: 'Lay Grotesk Trial'`, 24px, `letter-spacing: -1px`,
  `line-height: 45px`, `color: #0e0e0f`, `cursor: pointer`, `will-change: transform`,
  `transition: opacity .25s`. Non-hovered dim slightly when a sibling is hovered
  (`.lp-columns.hovering .lp-label:not(.active) { opacity: .55 }`).
- `.lp-card`: fixed, `width: 168px`, rounded 5px, overflow hidden, dark `#2a282f` base,
  `opacity: 0; transform: scale(.92); transition: opacity .18s, transform .18s`,
  `pointer-events: none`, `z-index: 30`. `.lp-card.visible { opacity: 1; transform: scale(1); }`.
  - `.lp-card-img`: aspect-ratio 1/1, `background-size: cover; background-position: center`.
  - `.lp-card-bottom`: gradient `transparent → #2a282f`, flex, padding, aligned to baseline.
  - `.lp-card-tag`: Inter/sans, ~8px, `rgba(255,255,255,.5)`, letter-spacing.
  - `.lp-card-name`: Inter/sans semibold, ~12px, white.
  - `.lp-card-more`: white, small, bottom-right.
